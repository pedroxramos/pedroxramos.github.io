# pedroxramos.github.io

Personal website of Pedro Xavier Ramos, PhD, expert CFD engineer in Antwerp.

One HTML page, no build step. The page is a character grid that works as a CFD mesh: the cursor sheds a von Kármán vortex street, clicks drop ripples with a water sound, and drifting bubbles show the selected works.

To add real footage to a work, set its `video` field in the `WORKS` object inside `index.html` and commit the clip next to it.
